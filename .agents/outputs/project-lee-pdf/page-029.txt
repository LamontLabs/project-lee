41. CIL Is Completely External 
 
CIL is a separate API service. 
 
LEE never performs CIL's specialist reasoning-routing logic internally. 
 
LEE sends a cognitive-resolution request to CIL. 
 
CIL determines: 
 
- whether governed reuse is available 
- whether new reasoning is required 
- what model capability is necessary 
- which model or model class should be selected 
- whether the request should be held 
- how much the chosen route is expected to cost 
 
LEE receives and follows that decision.
