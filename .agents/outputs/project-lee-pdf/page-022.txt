32. System Registry 
 
LEE should maintain a persistent record for each connected system. 
 
A System Registry entry can include: 
 
- system ID 
- name 
- version 
- description 
- system type 
- endpoint 
- runtime location 
- authentication method 
- current state 
- current health 
- last heartbeat 
- capabilities 
- permissions 
- governance requirements 
- dependencies 
- economics 
- owner approval
