66. Backup and Recovery 
 
LEE should support true recovery. 
 
A real backup should contain the authoritative information required to rebuild the Brain. 
 
Test Restore should: 
 
1. create isolated environment 
2. restore backup 
3. verify schema 
4. rebuild derived state 
5. verify invariants 
6. compare restored state 
7. return PASS/WARN/FAIL
