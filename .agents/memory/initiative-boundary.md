---
name: Initiative boundary
description: Initiative turns existing Lee evidence into optional, deduplicated operational observations rather than alarms or automatic actions.
---

Initiative items are significance-ranked observations with evidence references, expiry, cooldown deduplication, daily limits, and explicit acknowledge/dismiss controls; they never execute actions.

**Why:** Proactive awareness is valuable only when it is selective and non-prescriptive, not another notification stream.

**How to apply:** Generate from canonical state changes and pattern breaks, surface high-impact items first, preserve history after dismissal, and keep action hints optional language.
