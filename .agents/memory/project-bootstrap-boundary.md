---
name: Project Bootstrap boundary
description: Repository bootstrap converts observable static structure into auditable first-draft project knowledge and owner questions.
---

Bootstrap is evidence-first and advisory: it extracts stack, repository map, documentation/configuration/API inventory, summary, architecture signals, security observations, issues, and questions without reading secret values or executing repository code.

**Why:** A connected repository already contains much of the project reality Lee needs; the owner should only supply judgments the files cannot establish.

**How to apply:** Preserve source paths and confidence in every report, keep re-bootstrap history, surface missing or risky documentation as reviewable issues, exclude secret-bearing paths before content reads, and never treat inferred architecture as owner-verified fact.
