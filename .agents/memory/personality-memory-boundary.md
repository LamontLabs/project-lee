---
name: Personality Memory boundary
description: Model-independent personality continuity is stored in the canonical Brain and may affect presentation only.
---

Personality Memory is a versioned, owner-reviewable Brain record with explicit evolution history. It can shape tone, detail, challenge level, humor, and organization, but it cannot change facts, uncertainty, CIL routing, model choice, permissions, Constitution, CerbaSeal, owner authority, or Event Log integrity. Backup, restore, migration, and K6 authority-transfer evidence must prove that the active version and its evolution trail remain present and reversible.

**Why:** Personality continuity is useful across model and hardware migrations, but treating it as an authority surface would create an ungoverned second identity or hidden objective.

**How to apply:** Retrieve it after the universal identity stage, validate hostile content before activation, apply it only in response presentation, and fail closed to the safe baseline when its persisted safety status or evidence is invalid.
