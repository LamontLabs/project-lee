The Digital Twin Timeline is a filtered projection of Event Log records, not a duplicate event table. Significance configuration controls default visibility; milestone markers add explicit founder emphasis without mutating history.

**Why:** Operational history needs chronological navigation while preserving the Event Log as the authoritative append-only record.

**How to apply:** Add new timeline categories through significance configuration and keep exports, zoom levels, and filters derived from the same event projection.
