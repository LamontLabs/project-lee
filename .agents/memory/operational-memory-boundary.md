Operational Memory stages non-intrusive behavioral signals before promoting recurring time and activity patterns through candidate, established, strong, and historic states with evidence references.

**Why:** Recommendations need demonstrated operating rhythm, while preserving owner control and avoiding screen, keystroke, biometric, or health inference.

**How to apply:** Keep observations auditable, confidence/contradiction state explicit, manual overrides distinct and authoritative, and expose current-time context without sharing behavioral data externally.
